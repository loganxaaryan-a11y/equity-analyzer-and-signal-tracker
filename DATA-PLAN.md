## Long-term data behavior
- **Refresh policy**: fetch on open/search and on explicit Refresh; no cron or background refresh. Quote/search/SEC results always show source dates; 13F is labeled delayed.
- **Growth**: market/SEC data is ephemeral; journal and rule tables grow only through user input.
- **Ordering**: OHLCV oldest-first; institutional holdings by latest reported value; insider filings newest first; journal newest trade date first; rules in user-defined order.
- **Time semantics**: source market timestamps stay as returned; SEC report/filing dates stay as calendar dates; user-created timestamps render viewer-local; chart dates parse ISO strings directly, never epoch-zero fallbacks.

## 2026-10-01 methodology, news, and theories revision
- RSI-14 and ATR-14 now use Wilder smoothing: a simple 14-period seed followed by `(prior × 13 + new) / 14` for every subsequent observation. MACD, Bollinger bands, SMAs, and OBV remain unchanged.
- Performance windows are literal trading-session lookbacks from the latest bar: 7, 15, 30, 50, 90, 126, and 252 sessions. The UI keeps the familiar 6m/1y labels for 126/252 sessions.
- The old long/short percentage was removed from current analysis and watchlist presentation. The replacement is a signed factor-agreement score: `100 × Σ(weight × {-1,0,+1}) ÷ Σ(weights)`, with all factors, weights, readings, scores, and contributions displayed. It is explicitly not a profit probability. Historical tracked-signal rows retain their existing numeric column for compatibility but are presented as factor-agreement scores, not confidence probabilities.
- **Managed web search, used by `getNews`:** per-symbol search uses the resolved ticker plus the current date; discovery uses the current date plus macro, earnings, movers, and commodities. Returned URLs, titles, sources, snippets, and publication fields are preserved. A bounded inference step writes only a one-line why-it-matters interpretation and up to four ripple tags from each title/snippet. Every row is marked `Single-source result · unconfirmed`; when publication time is absent the retrieval time is shown instead. Search failures render an honest empty/error state.
- **Yahoo Finance chart endpoint, used by theories:** theory creation snapshots the latest available price for every linked ticker. Theory reads fetch current prices and recompute each prediction: expected-direction progress is confirming, an unachieved expired prediction is refuted, and other paths are challenged. Source endpoint pattern remains `https://query1.finance.yahoo.com/v8/finance/chart/{TICKER}?interval=1d&range=...`.
- **Artifact database:** user-created theories, predictions, ripple links, and attached news evidence are durable. Theories begin empty; no sample claims or evidence are seeded. Editing preserves original ticker snapshots so updating prose does not reset the test baseline.

## 2026-10-01 reference-architecture revision
- **Market Read:** fetches the selected instrument, SPY, QQQ, IWM, and up to the first watched instruments from the same Yahoo chart path. The 15-session breadth numerator and denominator are computed only from refreshed rows. Active flags come from the deterministic setup rules. The risk-adjusted leader is ranked by 30-session return divided by Wilder ATR as a percentage of price. Every instrument keeps its own source timestamp or an explicit error; any failed row triggers `PARTIAL FEED`.
- **Signal Tape:** the seven setup families are deterministic transformations of exact trading-session returns, Wilder ATR/RSI, volume z-score, Bollinger bandwidth, moving-average relationships, prior 20-session range, and aligned SPY ratio returns. Each card exposes measured aligned/conflicting checks and labels the result as alignment density, never probability. The post-earnings drift setup remains visibly unavailable unless a verified event-return series exists; no event is inferred from price action.
- **Rotation:** watchlist instruments (or QQQ/IWM/DIA only when the user watchlist is empty) are aligned to SPY by exact trading date. The 30- and 90-session values are changes in the asset/SPY price ratio; missing overlaps stay null.
- **Sizing:** all values are local calculator arithmetic from user inputs. Round-trip friction is `reference notional × basis points ÷ 10,000`; risk-sized shares divide the risk budget by stop distance plus per-share friction. Inputs are labeled assumptions, not predictions or execution estimates.

## 2026-10-01 two-layer history and deep-analysis revision
- **Layer 1 · Yahoo Finance full-history chart cache:** each symbol uses one explicit-period request with `period1=0`, `period2=<request time>`, `interval=1d`, and dividend/split events. The cache persists the complete daily series by symbol and refreshes at most once per UTC day; analysis, scans, and the cycle-context panel reuse that durable row. A mean-session-gap check rejects provider responses that silently downsample `range=max` to monthly data. If a daily refresh fails, a previously validated daily cache remains usable rather than causing a burst loop.
- **Adjusted-close decision:** Yahoo `adjclose` is preferred for every return, moving-average, drawdown, analog, and cycle calculation. Raw close is used only when the provider omits adjusted close for an observation. The chart and cycle panel label this basis; currency comes from the provider metadata and is rendered explicitly, including INR for `.NS` listings.
- **Politeness:** every Yahoo chart or quoteSummary request passes through one serialized process queue with a browser-compatible User-Agent and at least 650 ms between starts. HTTP 429 receives two exponential backoffs (800 ms, then 1.6 s); a third 429 abandons the pass. Automated scans therefore never burst even though their computation workers remain concurrent.
- **Full-history outputs:** the server computes every completed 20%+ adjusted-close drawdown, peak-to-bottom and bottom-to-recovery trading-session counts, bottom RSI-14, bottom distance from SMA-200, and 90-session forward base rate. It also computes current RSI/volume/20-day annualized-volatility percentiles over all usable history, five nearest three-feature historical analogs with subsequent 90-session returns, and named/most-recent annual highs and lows. The interface labels all of this historical base-rate context, never prediction.
- **Layer 2 · Yahoo Finance quoteSummary:** `runDeepAnalysis` is called only from the explicit per-ticker button and caches the raw provider response for six hours. The five lenses keep separate horizons and verdicts; unavailable short-interest, flow, policy, filing, or ownership inputs remain visible as unavailable and are never imputed. The take-private calculator shows every input and only computes `EBITDA × verified reference multiple − net debt`, per-share value, and distance when all required provider fields plus a user-entered verified comp multiple exist.
- **Deep-source failure behavior:** the current Yahoo quoteSummary endpoint returned HTTP 401 in the build sandbox, so the verified UI path renders all fundamentals and five lenses as unavailable rather than inventing them. Finnhub requires an authenticated API connection that is not present in this artifact runtime; no token or substitute fundamentals were fabricated. The existing Yahoo chart cache remains the price-history source and its stale validated row is the price-layer fallback when refresh fails.
